# 小红书 / 公众号封面设计

## 概述

把「标题 + 风格」变成一张可下载的封面图。整套方法来自歸藏的模块化封面提示词（CC BY 4.0），核心是让模型输出 **HTML/CSS 页面** 而不是直接画图——排版精度、中文字体、导出比例都完全可控。

提示词由四段组成，前两段按平台固定，第三段按风格替换，第四段由用户提供：

```
角色设定 + 基本要求  ←  base-prompts.md（按平台选）
风格要求             ←  styles.md（10 选 1）
用户输入内容          ←  本次的标题 / 文案 / 账号
```

## 工作流

### 第 1 步：收集输入

必需：**平台**（小红书 / 公众号）、**标题或文案**、**风格**。
可选：账号名、标语、背景图 URL、emoji 素材 URL。

用户没给风格时，按第 2 步的表格推荐 2-3 个并说明理由，让用户选；不要自己默默决定。
用户没给平台时默认小红书。

### 第 2 步：选风格

| # | 风格 | 适用场景 |
| --- | --- | --- |
| 01 | 柔和科技卡片风 | 产品数据、年度总结、SaaS 功能介绍 |
| 02 | 现代商务资讯卡片风 | 行业资讯、财经/科技新闻解读 |
| 03 | 流动科技蓝风格 | AI 工具、技术科普、开发者内容 |
| 04 | 极简格栅主义封面风 | 观点输出、设计感强的个人 IP |
| 05 | 数字极简票券风 | 活动预告、清单体、方法论拆解 |
| 06 | 新构成主义教学风 | 教程、知识体系、设计理论 |
| 07 | 奢华自然意境风 | 生活方式、旅行、品牌调性内容 |
| 08 | 新潮工业反叛风 | 职场吐槽、犀利观点、年轻向内容 |
| 09 | 软萌知识卡片风 | 泛知识、生活技巧、亲和力人设 |
| 10 | 商务简约信息卡片风 | 干货清单、职场效率、产品测评 |

需要看某套风格的完整描述或示例图时，读 `references/styles.md`（全文）和仓库 `prompt-assets/xhs-cover-prompts/styles/<目录>/preview-*.png`（示例图）。

### 第 3 步：拼装提示词

优先用脚本，避免手工拼接时漏段：

```bash
python3 scripts/build_prompt.py --list                 # 查看全部风格
python3 scripts/build_prompt.py --platform xhs --style 08 \
  --title "还在用 PPT？教你用 Claude 生成文档可视化网页" \
  --account "歸藏(guizang.ai)" --tagline "正儿八经学AI" \
  --out covers/prompt.txt
```

`--platform`：`xhs`（3:4）或 `wechat`（3.35:1，一次出 2.35:1 主封面 + 1:1 分享封面）。
`--style`：编号（`08`）、slug（`industrial-rebel`）或中文名（`新潮工业反叛风`）都行。
脚本默认从仓库 `prompt-assets/xhs-cover-prompts` 读资产，可用环境变量 `XHS_PROMPT_ASSETS` 覆盖。

手工拼装时顺序固定：基础提示词全文 → `## 风格要求：<风格名>` + 风格正文（去掉 `# 风格名` 这行）→ `## 用户输入内容` + 条目。

### 第 4 步：产出

两种方式，按环境选：

**A. 交给模型出 HTML**（默认）：把拼好的提示词整条发给支持 HTML 输出的模型，把返回的 HTML 存成 `covers/<标题 slug>.html`，浏览器打开即可用页面上的按钮下载封面。

**B. 直接写 HTML**：自己按提示词要求写页面，然后截图：

```bash
python3 scripts/render_cover.py covers/xxx.html --size 1080x1440   # 小红书
python3 scripts/render_cover.py covers/xxx.html --size 1080x322    # 公众号主封面 2.35:1
```

### 第 5 步：自检

交付前逐条确认：

- [ ] 比例正确：小红书 3:4，公众号整体 3.35:1
- [ ] 文字是视觉主体，占画面 ≥70%，主标题字号 ≥ 副标题的 3 倍
- [ ] 主标题提炼出 2-3 个关键词并做了特殊处理（描边/高亮/换色）
- [ ] 最外层卡片是直角，画布无边框，导出无留白
- [ ] 中文字体加载正常，长标题已换行，没有溢出或压字
- [ ] 页面有「下载图片」按钮且不影响版式（小红书用 html2canvas 导出）
- [ ] 风格特征与所选风格一致（配色、字体、装饰元素）

## 硬性规则

- **比例**：小红书严格 3:4；公众号整体 3.35:1，左 2.35:1 主封面 + 右 1:1 分享封面，两者共用背景与装饰。
- **文字占比**：≥70%，文字是主体，不是配图。
- **技术栈**：纯 HTML/CSS（小红书加 JS），Tailwind CDN + Google Fonts（或其它 CDN 字体），可引 Font Awesome。
- **导出**：小红书用 html2canvas，导出内容只含封面、不含界面元素；公众号页面底部提供整图下载按钮。
- **响应式**：容器高度随宽度按比例自适应，内部元素相对容器缩放，任何宽度下比例不变。
- **不要**：不要用 `<canvas>` 手绘排版，不要把文字做成图片，不要给最外层卡片加圆角。

## 新增风格

1. 用 `references/base-prompts.md` 末尾的「风格生成提示词」+ 1-5 张参考图，让模型输出三段式描述（设计风格 / 文字排版风格 / 视觉元素风格）。
2. 在 `prompt-assets/xhs-cover-prompts/styles/` 下建 `NN-slug/`，写入 `prompt.md`，参考图存为 `preview-N.png`。
3. 更新 `prompt-assets/xhs-cover-prompts/manifest.json` 与 README 索引表，把风格追加到 `references/styles.md`。

## 常见问题

- **导出图片模糊**：html2canvas 传 `scale: 2`；或把画布基准宽度设为 1080px。
- **字体没生效**：CDN 字体需 `document.fonts.ready` 后再导出，否则截到回退字体。
- **长标题撑破版面**：让模型先提炼 30-40 字精华，再按字号层级排；必要时手动断行。
- **公众号两图风格不统一**：强调「共享同一背景色与装饰元素」，只有尺寸和字数不同。
